# Swastya Assist V11.0.0 — safety hardening release

This release preserves the V10.4.4 UI and Gemini GenerateContent REST transport while hardening the clinical workflow.

## What changed

- Added facility model and facility-scoped case access for clinical users.
- Added persistent automated-vs-final reviewer risk values and required reasons for risk overrides.
- Added strict server-side validation for Gemini triage output before case persistence.
- Added conservative negation/historical guards to local urgency flags.
- Added untrusted-data boundaries to the triage prompt to reduce prompt-injection risk from patient/report content.
- Added server validation for supported voice source locales and translation languages.
- Added consent version, timestamp, and language metadata.
- Added synthetic/demo-mode direct-identifier blocking for common phone/Aadhaar/PAN/email patterns.
- Added referral/handoff state and destination tracking, including acknowledgement.
- Added reviewer UI controls for final operational priority, override reason, and referral state.
- Scoped reviewer packet access to the user's facility (admins retain system-wide access).
- Added regression/contract tests for the new safety controls.

## What did not change

- Existing UI layout and visual design were retained.
- Gemini GenerateContent REST transport was retained.
- Existing text, voice, OCR/report, dashboard, analytics, admin, and reviewer workflows were retained.
- No diagnosis, prescription, treatment recommendation, or autonomous clinical decision feature was added.

## Verification

- Python compile checks: passed.
- JavaScript syntax checks: passed.
- Isolated safety validator tests: passed.
- Full runtime pytest suite could not be executed in the build environment because Flask/Flask-SQLAlchemy/Flask-Limiter packages were not installed and outbound package installation was unavailable.

## Superseded by V11.0.2
The V11.0.2 release adds reviewer evidence/follow-up persistence, an explicit Insufficient information state, safe manual fallback when Gemini is unavailable, and referral transition guardrails.
