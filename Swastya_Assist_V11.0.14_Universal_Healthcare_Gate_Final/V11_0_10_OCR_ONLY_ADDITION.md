# Swastya Assist V11.0.11 — OCR-only addition

Only the standalone AI reports / OCR workflow was extended. Patient Intake and all other workflows retain their existing behavior.

Added to OCR results:
- Patient name shown from the report with match verification already enforced before output.
- Document type.
- Report/document date when readable.
- OCR quality indicator.
- Detected document sections.
- Clearly readable measurements/values with units/reference ranges when present.
- Explicit unreadable portions.
- Full source-document transcription labeled as OCR/source text.
- Reviewer-facing non-diagnostic reminder.

No diagnosis, prescription, treatment recommendation, or other clinical decision feature was added.
